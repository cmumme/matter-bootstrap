# Attack of the Killer Roombas
A port of [Matter's example game](https://github.com/matter-ecs/matter/tree/5dd81196496c307cbaab2ee735370ddb15cf7dd5/example) to [roblox-ts](https://roblox-ts.com) and [@rbxts/matter-bootstrap](/).

## Local development
To use this game to test local changes to [@rbxts/matter-bootstrap](/), run ``yarn local-dev`` in the [@rbxts/matter-bootstrap](/) directory, then ``yarn install`` in the example game directory. Everytime you make a change in [@rbxts/matter-bootstrap](/) re-run ``yarn local-dev`` to update the example game.
